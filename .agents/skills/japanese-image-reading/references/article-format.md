# 生成器输入

`build_reading.py` 使用 Python 标准库，不负责 OCR、翻译或推测读音。先核对内容，再交给它排版。

```json
{
  "stem": "022-人類のルーツ",
  "title": "人類のルーツ",
  "title_zh": "人类的起源",
  "furigana_title": "[人類|じんるい]のルーツ",
  "subtitle": "飛躍的にさかのぼっていく人類の起源",
  "subtitle_zh": "不断大幅向远古追溯的人类起源",
  "furigana_subtitle": "[飛躍的|ひやくてき]にさかのぼっていく[人類|じんるい]の[起源|きげん]",
  "source": "IMG_8771.heic",
  "pages": "22–23",
  "audio": "audio/022-人類のルーツ.mp3",
  "group": "原始时代",
  "paragraphs": [
    {
      "ja": "日本の歴史を学ぶまえに、人類の歴史についてまず知っておきたい。",
      "zh": "在学习日本历史之前，我们想先了解一下人类的历史。",
      "furigana": "[日本|にほん]の[歴史|れきし]を[学|まな]ぶまえに、[人類|じんるい]の[歴史|れきし]についてまず[知|し]っておきたい。"
    }
  ]
}
```

- 必需字段为 `stem`、`title`、`title_zh` 和至少一个包含非空 `ja`、`zh` 的段落。`stem` 是不带扩展名的文件名，不含目录。
- 副标题存在时同时填写日文和中译。原文没有副标题就省略这两个字段。
- 假名字段使用 `[字面|ひらがな]`。生成器验证移除读音后的文字与对应日文一致，转义 HTML 后渲染；读音准确性仍需人工核对。未要求假名时可省略这些字段。
- `audio` 可省略；提供时是输出根目录内已存在的音频相对路径，生成器不会调用 TTS 或下载音频。
- `source` 只用来源文件名；`pages` 可省略。不把私人绝对路径写入公开网页。
- `build_project.py` 额外要求 `stem` 以三位页码开头，`group` 为合集分组，且标题、副标题、正文有经过核对的假名。`speech` 可选，内容为与日文对应的可朗读文本，用于校正数字或专名读音；`numbering_note` 可选，用于解释用户指定编号与已有来源页码的差异。
- 默认不添加知识点。已存在的文稿由后续编辑保留并扩展，不能用新生成的对照正文覆盖。
